# 屈原的思想与人格

## 一、核心价值：「好修」与「美政」

`[文学]` 《离骚》反复出现的自我要求是「好修」——把道德与审美修洁当作终身事业。  
「美政」则是政治理想：举贤授能、循绳墨、反党人偷乐。人格与政纲在他那里是同一枚徽章的两面。

## 二、忠君与怨君的张力

他忠于楚、忠于「灵修」所代表的共治可能，同时激烈怨「不察」。  
这不是奴性愚忠，而是贵族对「共成美政」契约破裂的抗议。贾谊、司马迁以降的接受史强化了「忠」，有时减弱了「怨」的尖锐——细读文本两者都在。

## 三、香草美人：思维方式

屈原习惯把伦理冲突翻译成感官世界：芳／臭、美／恶、清／浊。  
好处是感染力极强；代价是容易被简化成符号解码游戏。正确用法：先感受场景，再谈 allegory。

## 四、死亡意识

从「宁溘死以流亡」到「从彭咸之所居」，死亡被设想为保持清白的最后手段。  
`[争议]` 彭咸事迹异说；重要的是屈原把「死」写成伦理选择，而非偶然结局。

## 五、与渔父哲学的对照

渔父劝「与世推移」；屈原坚持「凝滞于物」、不肯蒙世之尘埃。  
两种处世观在战国都有市场；文学史选择记住拒绝妥协的那一个，本身也是一种价值裁决。
