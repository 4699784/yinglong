# 屈原：生平与主要史料

## 1. 《史记》本传提要 `[史实]`（文献记载）

司马迁《史记·屈原贾生列传》是现存最早较完整的屈原传记，要点如下：

1. **族属与官职**：楚之同姓，名平，字原；博闻强志，明于治乱，娴于辞令；任**左徒**，应对诸侯，内议国事；又为**三闾大夫**。  
2. **见谗**：上官大夫妒其能，进谗于怀王；屈原被疏。  
3. **外交与政治**：主张联齐抗秦等；怀王屡误于秦，兵挫地削。  
4. **作《离骚》**：司马迁以「忧愁幽思而作《离骚》」释其创作动机，并引「《国风》好色而不淫，《小雅》怨诽而不乱」一派评价（此评亦见淮南王一系文学观）。  
5. **怀王入秦**：屈原曾谏；顷襄王立，屈原又遭令尹子兰等忌恨，**放流**。  
6. **泽畔行吟**：与渔父问答（《渔父》文与本传互见）。  
7. **沉江**：作《怀沙》，遂自投汨罗以死。

> 注意：上列为**史书叙事**；其中对话、赋篇系年含文学编排，须与 `[争议]` 条目对照。

## 3. 可较稳健采信的轮廓

在去掉精确年月日之后，较广泛接受的轮廓是：

- 屈原为战国楚贵族，参与政治与外交；  
- 因谗见疏，政治失意；  
- 与《离骚》《九章》等作品传统作者身份相连；  
- 最终在楚国败亡危机年代结束生命，汨罗沉江为强势早期传说/记载。

## 4. 「放逐」传统

`[争议]` 「一放」「两放」「疏而不放」等说并存。阅读时建议：

1. 先分清《史记》叙述层次与汉人注家增饰；  
2. 以作品内「流放—行旅—思郢」母题作文学分析；  
3. 勿用单一编年硬套全部《九章》。
