# 屈原作品概览与系年（慎用）

## 一、传统「二十五篇」与近人看法

王逸等以屈原作《离骚》《九歌》《天问》《九章》等。近现代对《远游》《卜居》《渔父》及《九章》个别篇、部分《九歌》作者归属多有讨论 `[争议]`。  
本库：**《离骚》《九歌》《山鬼》按传统屈赋／祭歌系统收入**；系年只给「气氛定位」，不给伪精确年表。

## 二、气氛系年（粗粒度）

| 阶段 | 气氛 | 常读作品 |
|------|------|----------|
| 见疏前后 | 忧思、自明、求用 | 《离骚》 |
| 流放江南 | 行旅、思郢、叹往 | 《九章》部分（本库暂未全文收录） |
| 巫祭改定／创作 | 人神、迎送、不遇 | 《九歌》 |
| 临终 | 明志 | 《怀沙》传统 |
