# 屈原相关学术争议（简表）

> 本篇只标争议焦点与常见立场，不替读者做最终裁决。

## 1. 有无其人

| 立场 | 要点 |
|------|------|
| 肯定（主流） | 《史记》本传、汉人吊屈、楚地纪念传统；否定说需更强反证 |
| 怀疑/虚化 | 近代个别学者疑屈原为传说英雄或文学符号 |

`[争议]` 完全否定其人者属少数；本库默认：**有历史人物屈原**，但其传记细节多不可精确还原。

## 2. 生卒年

诸说约在前 4 世纪中叶生、前 3 世纪前期卒；「生于寅年正月」据《离骚》「摄提贞于孟陬」推算，方法本身依赖历法与训诂选择 → `[争议]`。

## 3. 《离骚》等篇作者

| 范围 | 传统说 | 近现代讨论 |
|------|--------|------------|
| 《离骚》《九章》大部 | 屈原 | 基本仍多归屈原，个别篇目有疑 |
| 《九歌》 | 屈原作或屈原改作 | 屈原改民间祭歌 / 屈原作 / 非全出屈原 |
| 《天问》 | 屈原 | 多数仍归屈，性质特殊 |
| 《远游》《卜居》《渔父》等 | 旧多归屈 | 后出或门弟子/汉人拟作可能性被广泛讨论 |

## 4. 《九歌》与屈原关系（对《山鬼》尤重要）

王逸：屈原见民间祭歌鄙陋，故为作《九歌》。  
近人：或强调巫歌集体性与仪式功能，淡化「一人改作」叙事；或主张屈原运用祭歌形式创作。  

→ 读《山鬼》时可同时保留：**(A) 仪式祭歌传统**与 **(B) 屈赋抒情深度** 两层，而不必二选一消灭另一层。

## 5. 沉江与端午

`[史实]` 沉汨罗见于《史记》。  
`[传说]` 竞渡、粽子起源附会屈原，多为后起民俗整合；纪念屈原的民俗史本身值得研究，但≠战国史实复原。
