## 巫祭表演的基本动力学 `[文学]`

现代楚辞学常用模型（概括，非古书原词）：

1. **迎神**：铺陈车仗、佩饰、音乐。  
2. **留神 / 娱神**：人神对唱或巫代神言，常含爱恋、承诺、赠物。  
3. **送神 / 不遇**：神去、人留、失恋式怅惘——《山鬼》后半尤为典型。

## 「鬼」字辨

`[史实/训诂]` 上古「鬼」可指死者之灵，亦可泛指神灵、精怪；楚地「山鬼」不必等于后世厉鬼。王逸以来多以《山鬼》为「山神」。是否「鬼」低于「神」，属释义问题，见 `docs/楚辞/山鬼/学术要点.md`。
