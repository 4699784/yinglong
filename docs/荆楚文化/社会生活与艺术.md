# 荆楚社会生活与艺术（诗外之境）

## 一、都邑与乡野

郢都是政治与消费中心；沅湘泽畔、山阿幽篁则是《九歌》《九章》的文学地理。  
贵族可以同时熟悉朝堂礼仪与南方山水——屈原传统形象正是这种双栖者。

## 二、乐与舞

楚人尚乐舞，文物多见鼓、瑟、编钟等。  
《九歌》写「疏缓节兮安歌」「展诗兮会舞」「传芭兮代舞」，是可表演的提示，不只是形容词。鉴赏时不妨想象：有节奏、有轮舞、有香草传递。

## 三、服饰与身姿

长剑、玉珥、荷衣蕙带、高冠陆离——楚辞人物以「服饰修辞」塑造身份。  
山鬼的藤蔓装、东君的青云衣白霓裳、少司命的荷衣蕙带，各自规定了角色的「出场方式」。

## 四、生死观的两极

- 《国殇》：死而「神以灵」「鬼雄」——战死可祭、可荣；  
- 《山鬼》《湘君》：生者的等待与离忧——活着的人被时间折磨。  

荆楚文化并不只「浪漫」，也极「刚烈」。读全组《九歌》才能看到这枚硬币。

## 五、语言与方言色彩

楚辞含楚地方言词、独特虚字与名物。汉人已需作注。  
本库白话翻译求达意；遇关键名物仍指向古注，避免用北方常见植物硬套。
