# 名物与风俗（读《山鬼》《九歌》速查）

> 释义取常见古注与现代名物学共识；异说从略。层次多为 `[文学]` 名物 + 仪式象征。

| 辛夷 | 木兰类花木 | 为车 |
| 桂 | 桂树 | 为旗 |
| 石兰 | 兰类 | 为衣饰 |
| 杜衡 | 马兜铃科香草 | 为带 |

| 杜若 | 香草 | 「山中人」自况之芳 |
| 松柏 | 常绿乔木 | 庇荫；山居贞固 |

## 天候与声景

云、东风、神灵雨、雷填填、雨冥冥、风飒飒、木萧萧——共同制造**神临而不可久留**的氛围，亦写山中真实风雨经验。

## 服饰与赠答风俗 `[文学]`

「折芳馨兮遗所思」符合《九歌》常见的**鲜花香草为贽**；爱而不见则采三秀、饮石泉，以山中芳洁自持——与《离骚》芳草自喻传统相通。
