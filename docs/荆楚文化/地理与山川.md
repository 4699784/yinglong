# 地理与山川（荆楚 · 读诗用）

## 核心区域

`[史实]` 楚盛时疆域远超江汉，但《楚辞》高频地理意象仍集中在：

- **郢**：故都；政治与乡关象征。  
- **沅、湘、洞庭**：南巡、放逐、祭湘水神的空间。  
- **苍梧、九嶷**：南方远境与舜葬传说相关 `[传说/文学]`。  
- **汨罗**：传统屈原沉江之地（湖南汨罗江流域）`[史实]` 地名传承 + `[传说]` 细节附会。

## 「山」在《山鬼》中的功能

`[文学]`

1. **边缘空间**：相对都邑礼制中心，山是非常态、易遇非常之神的场所。  
2. **垂直结构**：「山之上 / 云在下」——神或巫表立高峰，云气隔绝人世。  
3. **阻隔**：「幽篁不见天」「路险难」——解释「后来」「不得闲」的相遇失败。

`[争议]` 有人坐实为巫山、荆山或某楚地南山；证据多为名物与后世附会，**无决定性史料**。本库建议：先完成文本结构分析，再谈地望假说。
