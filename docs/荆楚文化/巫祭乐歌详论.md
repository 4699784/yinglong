# 荆楚巫祭与乐歌详论

## 一、巫在楚：职能素描

`[文献]` 南方「信巫鬼，重淫祀」是汉人概括；楚简卜筮祭祷记录则显示巫祀与贵族生活深度嵌合。  
巫的可能职能包括：通神、医疾、祈雨、祓除、歌舞娱神。与中原祝宗卜史不必完全等同，但也不应漫画化。

## 二、祭歌的「戏剧语法」

《九歌》呈现出较稳定的表演逻辑：

1. **备物**：香草、酒肴、玉帛、乐器；  
2. **迎神**：沐浴更衣、车驾云旗；  
3. **留神／人神恋爱**：赠物、誓言、目成、同游；  
4. **神去／不遇**：升云、东行、未至、忘归之怅；  
5. **送神／成礼**：鼓舞传芭（《礼魂》）。

《山鬼》《湘君》《湘夫人》把第 3—4 步写到极致；《东皇太一》偏第 1—2 步的和乐；《国殇》则是另一祭类——战死者。

## 三、香草：仪式与道德的双编码

在祭场，香草是洁净与媚神；在屈赋，香草是人格 allegory。  
《九歌》更偏前者但仍可滑向后者；《离骚》更偏后者但仍保留佩饰动作的仪式感。读时应先问「这一草木在句中做不做祭具」，再问「它像不像君子」。

## 四、人神恋爱：不是现代言情的投影

「目成」「交手」「遗佩」「宿」「沐」等，是祭歌让神停留的语言。用现代恋爱小说逻辑去填情节，容易过度；但完全否认情欲与依恋的修辞，又会读瘪。恰当位置：**仪式修辞允许的亲密**。

## 五、对《山鬼》与全组的方法论

先问：这首歌在祭场完成什么功能？  
再问：屈原（若参与改作）加进了什么「不遇」的深度？  
最后才问：可否映射君臣？——第三问是可选项，不是入场券。
