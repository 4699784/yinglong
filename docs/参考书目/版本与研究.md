# 版本与研究书目（起步）

> 下列为公开展知的通行文献与研究门径，便于继续深挖。本库正文不取代原书。

## 一、文本与古注

1. 洪兴祖《楚辞补注》，中华书局（据《四部丛刊》等整理本通行）。  
2. 朱熹《楚辞集注》，上海古籍出版社等。  
3. 王逸《楚辞章句》（存于《补注》系统内，宜与洪氏合观）。

## 二、史部

1. 司马迁《史记》：卷四十《楚世家》、卷八十四《屈原贾生列传》。  
2. 《战国策》楚策相关各篇（策士言辞，审慎使用）。

## 三、神话与名物

1. 《山海经》（袁珂校注等通行本）。  
2. 楚辞名物专题：可检索「楚辞植物」「楚辞博物」类今人著作。

## 四、近现代研究门径（举例）

- 游国恩等《楚辞》研究与资料汇编类著作。  
- 姜亮夫《楚辞学》相关论著。  
- 汤炳正、金开诚、黄灵庚等《楚辞》校注、概论。  
- 民俗学/神话学视角讨论《九歌》的论文（检索「九歌巫祭」「山鬼」）。

## 五、使用原则

1. 先王逸、洪兴祖，后宋人义理与今人假说。  
2. 考古与简帛可校正文化偏见，但少有直接「山鬼篇」简文，勿附会。  
3. 引述时区分：原文 / 古注 / 今人推论。
