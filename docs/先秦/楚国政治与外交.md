# 楚国政治与外交（读屈原用）

## 一、国君与贵族

楚国权力结构大致是：王—令尹等执政贵族—各族世系。屈原所出之屈氏，与昭、景并为著名大族（「三闾」传统说与此相关）。  
贵族政治的好处是文化积累深；坏处是「党人」门户、谗毁容易伤害个别能臣——《史记》写上官大夫进谗，正是这一结构的叙事版。

## 二、联齐还是亲秦？

`[史实]` 楚的战略选择题长期是：

- **联齐**：东方大海与粮源、军援的想象；  
- **亲秦／畏秦**：西线压力巨大，和谈与婚姻外交反复。

张仪「献商於之地」欺诈，是教材级案例：怀王绝齐，地不可得，兵败名裂。屈原一系传统上被叙述为联齐派或至少反轻信秦人者。

## 三、「出使」与辞令

左徒职掌含「接遇宾客、应对诸侯」。楚辞作者群对「辞令」的敏感，既是外交实务，也是文学修辞的训练场。《离骚》的铺陈、对问、设誓，有辞令家的气息。

## 四、谏与疏：政治伦理的戏剧

楚史里充满谏而不听的悲剧结构（不独屈原）。屈原被经典化后，这一结构变成中国文学「忠臣—昏君—小人」的原型之一。  
史学上要谨慎：怀王并非无时无刻皆昏，但《史记》与骚赋共同塑造的「不察」形象，已足够解释作品中的愤怒与哀矜。
