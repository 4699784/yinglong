# 先秦历史脉络详述（楚相关）

> 目标：把「春秋争霸—战国七雄—楚亡于秦」写成可读的经历叙事，服务楚辞阅读。  
> 年代取约数；细节争议处标 `[争议]`。

## 一、周初到春秋：楚由「荆蛮」到大国

`[史实]` 西周封建格局中，楚处南土。周人文献常称「荆」「楚」，带中心—边缘视角。楚君早期称「子」，却逐步开疆。

关键节点：

1. **熊通称王（楚武王，约前 704）**：公开与周室分庭抗礼的政治宣告。  
2. **都郢传统**：文王都郢之说影响深远；郢地具体位置有多说 `[争议]`。  
3. **庄王霸业（前 613—前 591）**：问鼎轻重、邲之战胜晋，楚成为春秋超级大国之一。  
4. **柏举之役（前 506）**：吴师入郢，楚几乎亡国，后复国——说明楚既强也脆，都城与宗庙安全感并不永恒。

对读楚辞的意义：楚人有「我亦有国有祀」的自尊，也有都城可失的历史记忆；《哀郢》一类作品的沉痛，有这一长时段垫底。

## 二、战国：从极盛到削夺

`[史实]` 战国时代楚号称地方千里，却面临：

- **内部**：贵族政治、法制与人材竞争（吴起变法的短暂与挫折是典型切片）；  
- **外部**：齐、秦、韩、魏的合纵连横；秦自商鞅之后制度与军力上升。

怀王以前，楚仍是东方—南方的重量级玩家；怀王以后，战略失误叠加，国土与威望双降。

## 三、怀王—顷襄：楚辞的「当代史」

| 经历 | 大意 | 与文学 |
|------|------|--------|
| 怀王信张仪、绝齐 | 外交被骗，齐楚轴心破裂 | 「党人」「谗谄」叙事的政治土壤 |
| 丹阳、蓝田之败 | 丧师失地 | 「皇舆败绩」式恐惧可对读《离骚》 |
| 怀王入秦不返 | 国君被扣，死于秦 | 忠谏与「灵修」主题的高潮背景 |
| 顷襄避秦、前 278 拔郢 | 故都沦陷，东迁 | 《哀郢》传统系年核心 |
| 前 223 楚亡 | 负刍被虏 | 楚辞结集已入汉代 |

## 四、制度与社会：不只是「浪漫南国」

`[史实/考古]` 包山、郭店、上博等楚简证明：楚有系统法律文书、卜筮记录与思想文本。  
读《九歌》时，不宜把楚写成只有巫舞的化外；更准确的说法是：**礼制国家 + 浓厚巫祀地方传统并存**。

## 五、思想气氛（极简）

战国是诸子蜂起的时代：儒、墨、道、法、阴阳等并起。楚地既出《老子》传本相关文物语境，也出屈原这样的贵族诗人。  
楚辞的独特性在于：用巫祭、神话、香草美人，把**政治伦理危机**写成可唱可感的长诗与组诗——这在同时代文献中极为醒目。

## 六、阅读检查清单

读完本篇，应能回答：

1. 楚为何既能称霸又终亡于秦？  
2. 怀王、顷襄两朝哪些事件最常被拿来解释屈原作品气氛？  
3. 为何「郢都」在文学里如此沉重？
