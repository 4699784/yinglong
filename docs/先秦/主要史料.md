# 主要史料提要

## 一、史部与编年

| 文献 | 用途 | 注意 |
|------|------|------|
| 《史记·楚世家》 | 楚国世系、争霸、亡国 | 司马迁综合旧闻，细节需与他书互校 |
| 《史记·屈原贾生列传》 | 屈原生平最完整早期传记 | 含「渔父」式对话，文学性强 |
| 《战国策》（楚策等） | 纵横、外交、士人言辞 | 策士夸张，不可句句坐实 |
| 《左传》《国语》 | 春秋楚史与礼仪 | 时代早于屈原，供制度、文化对照 |

## 二、楚辞文本与早期注本

| 文献 | 通行认识 | 本库用法 |
|------|----------|----------|
| 《楚辞》（刘向辑、王逸章句系统） | 汉代结集的楚歌总集 | 正文底本参照洪兴祖《补注》系统通行文本 |
| 王逸《楚辞章句》 | 东汉最重要古注 | 神名、名物、作者归属的起点 |
| 洪兴祖《楚辞补注》 | 宋人补王逸 | 校异文、引旧说 |
| 朱熹《楚辞集注》 | 理学化解读 | 义理发挥多，需与古注区分 |

## 三、神话、地理与名物

| 文献 | 用途 |
|------|------|
| 《山海经》 | 山神、奇兽、山川想象；与「山鬼」类形象的比较材料 `[传说]` |
| 《淮南子》等 | 汉人整理的神话宇宙论 |
| 出土楚简、楚器铭文 | 校正礼俗、文字、思想 |

## 四、近现代整理（选）

详见 `docs/参考书目/版本与研究.md`。阅读《山鬼》时，建议至少对照：王逸注、洪兴祖补注、以及一种现代校注本（如游国恩主编《离骚纂义》类、姜亮夫/汤炳正/金开诚等诸家择一）。
