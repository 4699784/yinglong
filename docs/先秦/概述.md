# 先秦时代与楚：历史语境概述

> 目的：为阅读《楚辞·九歌》《山鬼》提供最小必要的时代框架。  
> 层次：以 `[史实]` 为主，辅以 `[争议]`。

## 1. 「先秦」指什么

`[史实]` 「先秦」通常指秦统一（前 221）以前的中国史分期，涵盖夏商周（含春秋、战国）。与楚辞直接相关的核心时段是：

| 阶段 | 约略年代 | 与楚/楚辞的关系 |
|------|----------|-----------------|
| 西周 | 约前 11 世纪—前 771 | 楚为南方诸侯，周人文献中多「荆楚」贬称 |
| 春秋 | 前 770—前 476 | 楚壮大，争霸；文化独特性强化 |
| 战国 | 前 475—前 221 | 屈原活动时代（传统系于楚怀王、顷襄王）；《楚辞》主要作品背景 |

`[争议]` 「春秋」「战国」分界有前 476 / 前 453 / 前 403 等说；本库取常见教材分期，不介入断代争论。

## 2. 楚的兴起与政治轮廓

`[史实]` 据《史记·楚世家》等：

- 楚先祖传说可上溯至颛顼一系；芈姓，早期君长称「楚子」。
- 西周至春秋：都城屡迁（丹阳、郢等），逐渐据有江汉流域。
- 春秋中后期：楚庄王等一度问鼎中原，与晋争霸。
- 战国：楚为「战国七雄」中疆域最广者之一；晚期屡败于秦，前 278 年秦将白起拔郢，楚徙陈、又徙寿春；前 223 年灭于秦。

`[史实/考古]` 江汉、江淮楚墓与简帛（包山、郭店、上博楚简等）显示：楚有发达的礼制、法律文书与思想文本，不宜简单视为「化外」。

## 3. 南北文化格局（阅读《九歌》所需）

`[史实]` 周鲁礼乐传统与楚地巫祀传统并存：

- 北方文献（《诗经》雅颂、《左传》礼制）强调贵族礼乐秩序。
- 楚地祭祀、乐歌、神祇谱系更重山川、云雨、日月与地方神（见《九歌》神名）。
- 王逸《楚辞章句》以《九歌》为「楚南郢之邑……其俗信鬼而好祠」的巫歌改编，此说影响深远。

`[争议]` 《九歌》是否屈原改作民间祭歌、是否全出屈原之手，近代以来多有讨论（见 `docs/楚辞/九歌/00-九歌总论.md`）。

## 4. 与屈原、楚辞相关的政治节点

| 约年 | 事件 | 文献依据（通行） | 备注 |
|------|------|------------------|------|
| 前 329 顷 | 楚威王卒，怀王立 | 《史记·楚世家》 | 屈原传统系年多落在怀王朝 |
| 前 313—前 312 | 张仪欺楚，楚齐绝交，丹阳、蓝田之战 | 《史记·楚世家》《屈原贾生列传》 | 屈原「使于齐」「谏怀王」叙事背景 |
| 前 299 | 怀王入秦被留 | 《史记》 | 屈原「昭王后」系年争议之关键 |
| 前 278 | 白起拔郢 | 《史记·秦本纪》《楚世家》 | 传统「屈原沉江」多系顷襄之世、郢都沦陷前后 |
| 前 223 | 秦灭楚 | 《史记》 | 楚辞成书、结集在汉 |

`[争议]` 屈原生卒年无精确铭文；常见推定约前 340—前 278 前后，异说甚多。详见 `docs/屈原/`。

## 5. 史料类型与使用原则

1. **正史叙事**：《史记·楚世家》《史记·屈原贾生列传》——最常用，但含文学化与汉人视角。  
2. **楚地出土文献**：法律、卜筮、思想类简——校正「楚唯蛮夷」刻板印象。  
3. **《楚辞》本文及其汉唐注**：王逸、洪兴祖、朱熹等——文学与祭祀语境的主渠道。  
4. **神话地理**：《山海经》等——与山神、灵怪想象相关，属 `[传说]`/`[文学]` 互证材料，不可直接当编年史。
