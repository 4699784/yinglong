# 《山鬼》创作背景

## 一、文体与组诗位置

`[文献]` 《山鬼》为《楚辞·九歌》之一。通行本《九歌》十一篇，大致自天神、云日，而至山川人鬼；《山鬼》近「山灵／人鬼」一端，后再接《国殇》《礼魂》。

`[争议]` 「九歌」名义：或古乐名（《离骚》称夏启有《九歌》），或「九」虚数，或实指篇数（与十一篇不合）。作者传统归屈原，王逸谓屈原改定楚地民间祭歌。近人有重巫祭集体性、淡化「一人改作」者。本库取：**楚祭歌传统 + 屈赋抒情深度**双重视角。

## 二、楚地巫祀与「信鬼好祠」

`[文献]` 王逸《楚辞章句》言楚南郢之邑「其俗信鬼而好祠，其祠必作歌乐鼓舞以乐诸神」。  
《汉书·地理志》等亦记南方巫鬼之风。结合《九歌》神谱（东皇太一、云中君、湘君湘夫人、司命、东君、河伯、山鬼等），可见：

1. 祭祀含乐歌与巫的扮演；  
2. 人神之际常用爱恋、赠物、迎送结构；  
3. 香草、车仗、云雨是仪式语言，也是诗的意象语言。

《山鬼》正是这一背景下「山中之神」的专祀乐歌——无论是否经屈原润色，其**发生土壤**是荆楚巫祭，而非中原雅颂朝会。

## 三、时代气氛（战国楚）

`[史实]` 屈原活动传统系于楚怀王、顷襄王时期；楚与秦争衡，怀王入秦不返，顷襄之世郢都终陷（前 278），楚势日蹙。  
`[文学]` 《九歌》不必篇篇系于某战役之年，但整组诗的抒情气质——暂聚、速散、不遇、死烈（《国殇》）——与战国楚人的危机感、宗教热情可以互相照明。

将《山鬼》硬钉在「白起拔郢之年所作」之类，证据不足，宜标 `[争议]`。

## 四、可能的创作／改定动机（诸说并列）

| 说法 | 要点 | 层次 |
|------|------|------|
| 王逸改作说 | 民间祭歌鄙陋，屈原改作 | 古注主流 |
| 屈原创作说 | 用祭歌形式写一己之情 | 文学史常见 |
| 民俗残留说 | 文本保存巫祭结构，作者问题次要 | 现代民俗学视角 |
| 政治寄托说 | 山鬼候人不遇＝君臣不遇 | 接受史强势，文本非唯一解 |

阅读策略：把「巫祭背景」当作地板，「屈原抒情」当作可叠加的天花，而不是用后者拆掉前者。

## 五、文本流传背景

汉代刘向辑《楚辞》，王逸作《章句》，宋洪兴祖《补注》、朱熹《集注》等层层加注。今所见《山鬼》正文，大体稳定于这一注疏传统；名物、句读、异文细节见 `异文与版本提示.md` 与 `docs/参考书目/`。
