# 《山鬼》全文与解题

> 本卷为 Project「shan gui」核心文本库。  
> 正文简体；注释见 `逐段注.md`。

## 全文

若有人兮山之阿，被薜荔兮带女萝。  
既含睇兮又宜笑，子慕予兮善窈窕。  
乘赤豹兮从文狸，辛夷车兮结桂旗。  
被石兰兮带杜衡，折芳馨兮遗所思。  
余处幽篁兮终不见天，路险难兮独后来。  
表独立兮山之上，云容容兮而在下。  
杳冥冥兮羌昼晦，东风飘兮神灵雨。  
留灵修兮憺忘归，岁既晏兮孰华予？  
采三秀兮於山间，石磊磊兮葛蔓蔓。  
怨公子兮怅忘归，君思我兮不得闲。  
山中人兮芳杜若，饮石泉兮荫松柏。  
君思我兮然疑作。  
雷填填兮雨冥冥，猿啾啾兮狖夜鸣。  
风飒飒兮木萧萧，思公子兮徒离忧。

## 解题

### 篇名

`[训诂]` 「山鬼」：山中之神灵。王逸《楚辞章句》以之为「山神」。上古「鬼」可涵盖神灵，不必作后世「恶鬼」解。是否「位低于正神」，属阐释问题，见 `学术要点.md`。

### 传统题解（王逸系）

大意：楚人祀山神之歌；写山神（或山中女神）形貌、车从、候人之情。屈原改作民间祭歌之说见《九歌》总论。

### 本库立场（阅读策略）

1. **先仪式，后寓意**：优先还原巫祭「迎候—不遇—离忧」表演逻辑。  
2. **再文学**：分析人称、视角、声景与时间。  
3. **慎自传**：以屈原自喻为可选层，不作唯一解。  
4. **标争议**：性别、地望、「灵修／公子／君」所指，均入争议表。
