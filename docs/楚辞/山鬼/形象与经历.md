# 《山鬼》中的「人物」经历

> 本篇所说「人物」，首先指诗中的**山鬼（山中神灵／巫所扮演之神）**；其次涉及传统叙事中与屈原、楚巫相关的经历层。  
> 请区分：`[文学]` 诗内情节 · `[传说]` 后起附会 · `[史实]` 可征文献 · `[争议]` 未定之说。

## 一、诗内经历：一次赴约而未遇

`[文学]` 《山鬼》几乎可以读成一出短剧。主角的经历按时间推进如下：

| 阶段 | 诗中事件 | 情绪 |
|------|----------|------|
| 出场 | 山阿之人现身，披薜荔、带女萝，含睇宜笑 | 自信、美好、被慕 |
| 整装上路 | 乘赤豹、从文狸，辛夷车、桂旗；再饰石兰杜衡，折芳欲赠 | 郑重、期待 |
| 受阻迟到 | 幽篁不见天，路险难，独自来迟 | 焦灼、自责 |
| 山巅候望 | 独立山上，云在脚下；昼晦、东风、神雨 | 孤高而凄清 |
| 欲留所思 | 想留住「灵修」，又忧岁晏谁使己荣华 | 挽留、迟暮恐惧 |
| 山中采芝 | 乱石葛蔓间采三秀；怨公子、怅忘归；自我安慰「君思我但不得闲」 | 怨而不绝 |
| 自持 | 山中人芳如杜若，饮石泉、荫松柏；信疑交作 | 贞定又动摇 |
| 夜深空候 | 雷雨猿鸣、风木萧萧；思公子而空有离忧 | 徒然、余恨 |

这是**一次失败的相会**：不是战斗史传，而是候神／恋爱式祭祀里最常见的「人待神、神不来（或来而即去）」经历。

## 二、山鬼是谁？经历属于谁？

### 1. 山中女神／山神 `[文学]` + `[争议]`

古注多以「山鬼」为山神。诗中「含睇」「宜笑」「窈窕」使形象强烈女性化，故今读多作**山中神女**。  
其「经历」即上表：自山中来赴所思之约，而终不遇。

### 2. 巫的扮演经历 `[文学]`

若置于《九歌》巫祭场：巫妆为山鬼，载歌载舞，代神言、代情人言。则「经历」也是一场**仪式表演中的角色弧线**——迎、留、怨、送（或神隐）。

### 3. 屈原自况？ `[争议]`

后世常把「岁晏」「灵修」「离忧」读成屈原忠而见疏的投影。  
- 合理处：与《离骚》「迟暮」「灵修」「不遇」同构。  
- 风险处：把祭歌压缩成政治自传，会抹掉山野、香草、兽从等巫祭质地。  

本库建议：**先完成诗内山鬼经历，再谈屈原互文**，二者可并存，不必互相消灭。

## 三、与屈原生平叙事的对照（接受史）

`[史实]` 屈原放逐、行吟泽畔、沉汨罗，见《史记·屈原贾生列传》。  
`[文学]` 读者若带着「忠臣失路」的期待来读《山鬼》，会特别放大「后来」「不得闲」「徒离忧」。  
这属于**阅读经历**，不等于诗写成于某次具体放逐途中——后者缺乏篇内自证，系年多属推测 `[争议]`。

## 四、一句话提纲

山鬼的「人物经历」＝盛装赴约 → 路险迟到 → 云雨中久候 → 采芳自慰 → 雷雨夜里空余离忧。  
读懂这一弧线，翻译、解析、鉴赏才有共同骨架。
