# 《山鬼》学术要点与争议

## A. 较成共识或高共识

1. 《山鬼》属《九歌》组诗，写山中神灵与候人之情。  
2. 文本充满巫祭乐歌特征（妆束、神驾、云雨、赠芳）。  
3. 抒情结构以「赴约—迟到/不遇—岁晏—离忧」为主干。  
4. 名物训诂大体可依王逸—洪兴祖及现代名物学整理。

## B. 主要争议

| 议题 | 常见说法 | 本库建议 |
|------|----------|----------|
| 山鬼性别 | 女神为主流；亦有山神（可男）说 | 文本「含睇宜笑」「窈窕」偏女性美；表演中可由巫扮演 |
| 「鬼」是否贱于「神」 | 有人谓山鬼为魅；有人谓楚「鬼」即神 | 先作山神灵理解；「魅」说需额外证据 |
| 人称视角 | 山鬼自述 / 巫述神 / 对唱残留 | 以山鬼（巫扮）第一人称为便读；承认或有角色转换 |
| 灵修、公子、君 | 同一情人；或君王；或神 | 祭歌层：所思对象；屈赋互文层：可选 |
| 地望 | 巫山、荆山、泛指楚山 | 无硬证；勿先坐实 |
| 作者 | 屈原作 / 改作 / 非全出屈原 | 传统归屈原；分析时兼顾集体祭歌传统 |
| 政治 allegory | 忠君不遇之喻 | 可作接受史一层，不宜取代字面与仪式 |

## C. 与《离骚》互文的「可控」用法

合理互文：香草、迟暮、灵修、不遇。  
过度解读：句句比附怀王、党人、具体政局。  
原则：**互文是加成，不是翻译密码。**

## D. 研究切入建议（给 shan gui 项目）

1. 做一次「人称与角色」细读表（逐句标说话者）。  
2. 做声景—时景表（云、雨、雷、猿、风木 × 昼夜）。  
3. 对照《湘君》《云中君》《东君》「忘归／不闲」句群。  
4. 若涉视觉改编：赤豹文狸、辛夷桂旗、幽篁山巅是稳定图像母题。
