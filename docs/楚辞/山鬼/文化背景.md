# 《山鬼》文化背景

## 1. 巫祭语境

`[文献]` 王逸谓楚人「信鬼而好祠」，《九歌》源于南郢邑之巫歌。无论是否经屈原改写，诗中：

- 香草佩饰、兽车桂旗 → 迎神妆束与道具；  
- 山巅云雨 → 神显场域；  
- 折芳遗所思、留灵修 → 留神/媚神；  
- 不遇与离忧 → 送神或神隐后的人情余波。

`[文学]` 可将全篇读作一场**失败的约会式祭祀**：角色登场极美，时空却错位。

## 2. 山中之神与《山海经》比较材料

`[传说]` 《山海经》记诸山有神，形貌或人面兽身、或司山川风雨。  
《山鬼》则几乎全盘**美人化**，仅以赤豹文狸保留山野神性。  
→ 比较价值在于：同属「山灵」想象，艺术策略不同——经记怪，歌写情。

## 3. 「巫山神女」与后起传说

后世常将《山鬼》与巫山神女（宋玉《高唐》《神女》系统）联想。  
`[争议]` 二者时地、文体不同；可作接受史、主题学比较，**不能直接等同为同一神》。

## 4. 香草与楚俗

见 `docs/荆楚文化/名物与风俗.md`。要点：薜荔、女萝、石兰、杜衡、杜若、三秀构成「山中香草衣柜」，与《离骚》园圃香草、《湘夫人》水上香屋，共同组成楚辞芳香符号宇宙。

## 5. 自然经验

江汉、沅湘多竹、多雨雾、多山谷回声。诗中「幽篁不见天」「神灵雨」「猿狖夜鸣」既是神境，也是可感的南方山地经验——仪式象征与地方生态不必对立。
