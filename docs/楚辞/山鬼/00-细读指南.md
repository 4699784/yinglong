# 《山鬼》细读指南

建议按下列顺序阅读本卷（由事到文，由译到赏）：

1. **创作背景** — 巫祭与时代土壤  
2. **形象与经历** — 诗中「人物」经历弧线  
3. **全文与解题** — 古典正文  
4. **白话翻译** — 逐句今译 + 连贯白话  
5. **逐段注** — 名物与训诂  
6. **解析** — 结构、人称、意象、主题  
7. **鉴赏** — 审美与读法  
8. **文化背景 / 学术要点 / 异文与版本提示** — 进阶
