# 《山鬼》白话翻译

> 翻译原则：求达意与语气，不逐字死扣；古典正文据通行本（简体）。  
> 层次：翻译属 `[文学]` 今译，便于进入解析与鉴赏；精细训诂见 `逐段注.md`。

## 原文与今译对照

**若有人兮山之阿，被薜荔兮带女萝。**  
仿佛有个人儿在山弯深处，身上披着薜荔，腰间缠着女萝。

**既含睇兮又宜笑，子慕予兮善窈窕。**  
目光微微流转，笑起来又正好看——你爱慕我，正因我美好窈窕。

**乘赤豹兮从文狸，辛夷车兮结桂旗。**  
我乘着赤豹，文狸跟在身后；辛夷木做的车子上，结着桂枝的旗帜。

**被石兰兮带杜衡，折芳馨兮遗所思。**  
再披上石兰、佩上杜衡，折一束芳香，要送给心上思念的人。

**余处幽篁兮终不见天，路险难兮独后来。**  
我住在深竹林里，整日望不见天光；道路又险又难，所以独自来迟了。

**表独立兮山之上，云容容兮而在下。**  
我特特站在高山顶上，云气滔滔，都在我脚下浮动。

**杳冥冥兮羌昼晦，东风飘兮神灵雨。**  
幽暗无边，白日也像夜一般昏黑；东风吹来，雨像有神灵随行。

**留灵修兮憺忘归，岁既晏兮孰华予？**  
我想留住我所敬爱的人，让他安然沉醉以至忘归；可一年已晚，还有谁能使我再绽放荣华？

**采三秀兮於山间，石磊磊兮葛蔓蔓。**  
我在山里采那一年三度开花的芝草，只见乱石磊磊、葛藤蔓蔓。

**怨公子兮怅忘归，君思我兮不得闲。**  
我怨着公子，惆怅得忘记归去；——想来你也思念我，只是不得空闲吧。

**山中人兮芳杜若，饮石泉兮荫松柏。**  
我这山中人，芳香如同杜若；喝的是石间清泉，歇在松柏树荫下。

**君思我兮然疑作。**  
说你思念我——我忽而相信，忽而又怀疑。

**雷填填兮雨冥冥，猿啾啾兮狖夜鸣。**  
雷声填填，雨意冥冥；猿猴啾啾，长尾猿也在夜里啼叫。

**风飒飒兮木萧萧，思公子兮徒离忧。**  
风声飒飒，树木萧萧；我想念公子，却只空留下这离别的忧愁。

## 连贯白话（可朗读）

山弯里仿佛有个人，披着薜荔，束着女萝。她眼神含情，笑意正好，你爱她，正因为她那样窈窕。

她乘赤豹，文狸相随，辛夷为车，桂枝为旗；又饰石兰杜衡，折了香花要送给思念的人。可她住在深竹里终日不见天，路又险，所以来晚了。

她独自立在山顶，云在脚下涌动。白昼昏暗，东风带着神雨。她想留住心上人，让他安然忘归；可年岁已晚，谁还能给她荣华？

她在乱石葛藤间采灵芝，怨着公子，惆怅忘归；又宽慰自己：你想我，只是忙罢了。她是山中人，芳如杜若，饮石泉，荫松柏——可「你想我」这句话，她信了又疑。

雷响雨暗，猿啼夜深，风过木响。她思念公子，到底只剩空空的离忧。
