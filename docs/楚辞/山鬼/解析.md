# 《山鬼》解析

> 解析＝拆解结构、人称、意象与主题。属 `[文学]`；训诂细节见 `逐段注.md`。

## 一、整体结构：四段式情感曲线

可粗分为四节（非古本分段，便于讲解）：

1. **亮相与赴约**（「若有人」→「遗所思」）  
   外貌、车从、赠芳：建立「美」与「有所待」。
2. **受阻与升登**（「幽篁」→「神灵雨」）  
   空间垂直化：从不见天的竹林，到云下之山巅；天候神迹化。
3. **挽留与自解**（「留灵修」→「然疑作」）  
   时间焦虑（岁晏）+ 心理摆荡（怨／谅／信／疑）。
4. **声景收束**（「雷填填」→「徒离忧」）  
   几乎纯听觉；人未至，忧独留。

情感不是直线悲伤，而是：**盛装期待 → 自责迟到 → 孤傲等候 → 自我安慰 → 自我拆穿 → 空余离忧**。

## 二、人称与视角

诗中出现「予／余」「子」「灵修」「公子」「君」「山中人」等：

| 称呼 | 常见理解 | 解析要点 |
|------|----------|----------|
| 予、余、山中人 | 山鬼（或巫扮山鬼）自称 | 第一人称主视角 |
| 子 | 对方（所慕者） | 「子慕予」奠定被爱的开局 |
| 所思、灵修、公子、君 | 多指同一候望对象 | 亲昵／敬爱层次不同；是否即楚王属 `[争议]` |

`[争议]` 是否有巫／神对唱残留？本库默认「山鬼独白」最顺；若遇语气骤变，可标为表演中的角色转换，而不必强改字句。

## 三、空间与时间

**空间**

- 山阿、幽篁：封闭、潮湿、隔绝。  
- 山之上／云在下：神圣垂直空间，也是「看得见却等不来」的瞭望台。  
- 石磊磊、葛蔓蔓：荒寒劳动场景，反衬采芝的芳洁意志。

**时间**

- 「后来」：错过的节点。  
- 「岁既晏」：季节／青春／政治时机的叠合隐喻。  
- 「夜鸣」：把等待拖入夜间，完成一天的失败。

## 四、意象系统

1. **香草佩饰**：薜荔、女萝、石兰、杜衡、杜若、三秀——洁与媚神，亦是身份符号。  
2. **兽从车仗**：赤豹、文狸、辛夷车、桂旗——标明「非常之人」，山野版神驾。  
3. **云雨雷风猿木**：神显与神隐的天候声景；越到后半，视觉越少、听觉越多，孤独越硬。

「折芳馨兮遗所思」是《九歌》常见的**礼物母题**；礼物备好而人不至，礼物便转化为忧的证据。

## 五、主题：不遇

《山鬼》的核心不是「山很美」，而是**不遇**：

- 约会结构失败（路险／不得闲／疑信）；  
- 与《湘君》《湘夫人》的候而不至同型；  
- 与《离骚》上下求索而不遇哲王／美女可互文，但场景一在山野祭歌，一在神话政治旅行。

「徒离忧」的「徒」字是主题词：一切妆饰、攀登、采芝、宽慰，结果仍是空。

## 六、与《九歌》内部对照（简表）

| 篇 | 聚散类型 | 与《山鬼》 |
|----|----------|------------|
| 云中君 | 暂降即逝 | 同「不留」 |
| 湘君／湘夫人 | 期而不至、捐佩遗芳 | 句式「不得闲」可互参 |
| 东君 | 声色娱人、憺忘归 | 「憺忘归」用语相近，公众祭 vs 私候 |
| 国殇 | 死而神灵 | 「鬼」字同组，语义不同 |

## 七、解析结论（可带进鉴赏）

《山鬼》用巫祭「迎候」外壳，写尽个体在等待中的尊严与崩溃边缘：她始终美、始终芳、始终自持，却无法把「君」等来。美与空，同时成立。
