# 《山鬼》异文与版本提示

> 本库正文取通行教学/整理文本（简体）。精细校勘请回到原刻本。

## 常见需留意之处

1. **於山间 / 于山间**：通假与简化问题，义同。旧注或读「於」为「巫」相关地名（「巫山」），属 `[争议]` 训诂，非常见必从之说。  
2. **狖**：猿类；字或作「又」声系异体问题，义指山中猿鸣即可。  
3. **三秀**：芝草说最通行；亦有他解，但不影响「山间采芳」结构。  
4. **句读**：「君思我兮然疑作」常独立成短句，加重心理顿挫——本库从之。

## 推荐对读版本（见参考书目）

- 洪兴祖《楚辞补注》（中华书局等）  
- 朱熹《楚辞集注》（看义理发挥，勿单用）  
- 一种现代校注译本（金开诚、黄灵庚、汤漳平等诸家择一）
