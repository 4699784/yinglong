# 《离骚》创作背景、意译提要与鉴赏

## 一、创作背景

`[文献]` 《史记·屈原贾生列传》：屈原被谗见疏，「忧愁幽思而作《离骚》」。又释「离骚」为「犹离忧也」（遭忧）。异解尚有「离别之愁」等 `[争议]`。

时代背景：楚怀王前后，楚秦博弈失利，朝中谗谄竞进；屈原由近臣变为见疏者。《离骚》不是日记，而是把这一政治—伦理危机，写成香草美人、上下求索的巨幅象征诗。

## 二、人物经历在诗中的投影（提要）

1. 自报世系与美名 → 确立高贵起点；  
2. 修能佩芳、愿为王先路 → 用世热情；  
3. 灵修改路、党人偷乐 → 政治背叛感；  
4. 女嬃告诫、就舜陈词 → 自我辩护；  
5. 上征求女失败 → 求知己／求合君皆空；  
6. 灵氛巫咸劝去国，临睨旧乡不能行 → 去留撕扯；  
7. 乱辞「从彭咸之所居」 → 以死殉志的伦理选择（彭咸事迹有争）。

详见 `分段导读.md` 与 `全文.md`。

## 三、白话意译（结构提要，非逐句全译）

《离骚》篇幅大，这里提供**可抓住主线的意译提要**，便于与《山鬼》对照：

我是古帝高阳的后人，父亲给我美好的名字。我既有内在之美，又加修养与才能，把香草佩在身上，生怕岁月不等我，生怕美人迟暮。我想为君王作先导，可君王听信谗言，中途改道。我栽培的兰蕙被众芳污染，我宁可九死也不悔我所珍爱的。女嬃劝我别太方正；我南渡沅湘，向舜陈说历史的兴亡。我驱龙乘凤上天叩门，求宓妃与佚女，却总是不遇。灵氛、巫咸劝我远走；世上芳草变臭，我只好准备远行——可一回头看见故乡，仆夫与马都悲伤得走不动。算了罢：国中无人理解我，美政无从实现，我只有追随彭咸的归宿。

（逐句全译可后续扩展；阅读全文时请仍以 `全文.md` 为准。）

## 四、解析要点

- **象征系统**：香草＝君子／修洁；美人／灵修＝理想君主或理想政治关系；求女＝求合。  
- **空间**：地上朝堂 ↔ 天上神境 ↔ 旧乡；最终被「旧乡」锁住。  
- **时间**：迟暮恐惧贯穿全篇。  
- **伦理**：惜诵、好修、死直——价值高于存活策略。

## 五、鉴赏：与《山鬼》对读

| | 《离骚》 | 《山鬼》 |
|--|----------|----------|
| 体量 | 长篇政治—神话抒情 | 短篇巫祭抒情 |
| 不遇 | 求女、叩阍、哲王不寤 | 候人不至 |
| 自持 | 芰荷衣、昭质未亏 | 杜若、石泉、松柏 |
| 收束 | 从彭咸 | 徒离忧 |
| 声音 | 长太息、陈词 | 雷雨猿风 |

二者都写「等待与失败」，但《离骚》把失败上升到美政与生死，《山鬼》把失败收束在一夜山中的离忧。先读《山鬼》的密而短，再读《离骚》的广而长，是很好的进阶路径。
