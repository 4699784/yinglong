# 《离骚》鉴赏

## 一、宏大而仍私密

《离骚》上天下地，却始终贴着一颗受伤的心。奇幻不是为了炫博，而是给「不被理解」找一个足够大的舞台。读时既要跟飞龙走，也要听见掩涕的声音。

## 二、香草世界的美学

佩兰餐英、制荷为衣，把道德写成可嗅可触的美。中国文学此后「美人香草」传统，很大程度从这里取得许可证。鉴赏焦点：美不是装饰，是立场。

## 三、最动人的停顿：「临睨旧乡」

准备远逝、千乘云旗，却在俯见故乡时「蜷局顾而不行」。  
一切宇宙旅行的加速度，被一个回头刹住——这是政治诗少有的、近乎生理的乡愁。

## 四、怨的品格

《离骚》的怨不是咒骂发泄，而是「九死未悔」前提下的痛。怨得有节，正是司马迁所谓「《小雅》怨诽而不乱」一派评价能够成立的原因（评价本身也属接受史）。

## 五、如何读才不累

建议：先读 `白话翻译.md` 抓线，再选古典正文慢读两三段（开篇、九死未悔、乱辞），然后看解析。不必一次「征服」全篇字词。

## 六、与《山鬼》合读的收获

短的《山鬼》教会你听「徒离忧」；长的《离骚》教会你看「美政不可为」。一个是夜山的空，一个是故国的沉——合起来，才接近屈原世界的全幅。
