# 《离骚》解析

## 一、文体与规模

《离骚》是骚体长诗的典范：以「兮」字句为主，铺陈、设问、神话旅行、乱辞收束。它不是纪事散文，而是**象征化的精神自传**。

## 二、结构再归纳（六块）

1. 自报家门与修能（确立主语）  
2. 政治失望与党人（确立冲突）  
3. 好修与九死未悔（确立伦理）  
4. 女嬃—重华（确立自我辩护的历史法庭）  
5. 上征求女与占卜去留（确立「不遇」的宇宙版）  
6. 远逝而顾乡 + 乱辞（确立悲剧结局）

## 三、关键象征

| 象征 | 常见对应 | 解析提醒 |
|------|----------|----------|
| 香草 | 君子、修洁、人材 | 先是可佩可植的物，再是 allegory |
| 灵修／美人 | 理想君主或理想政治关系 | 不必句句＝怀王 |
| 求女 | 求合、求知己 | 多层，勿只读成情诗 |
| 党人／众女 | 谗谄集团 | 性别修辞，非实写后宫斗争史 |
| 彭咸 | 以死谏／以死守志的前贤模板 | 事迹有争 |

## 四、叙事动力：「求」与「不遇」

全诗被「求」推动：求用、求察、求女、求同道、求去国之安。  
每一次「求」都以「不遇」或「不能」结束，最后连「去」也被故乡绊住。  
与《山鬼》的「候」同属不遇家族，但《离骚》把不遇扩成家国与生死问题。

## 五、声音与人称

大量第一人称长太息、指天为证、陈词、占问，造成「独白法庭」效果：诗人同时是原告、证人与即将赴死的当事人。

## 六、乱辞的功能

「乱」为乐章尾声／卒章显志。「国无人莫我知」「从彭咸之所居」把全诗的政治失败收束为伦理抉择，力度大于任何中间的神话奇观。
