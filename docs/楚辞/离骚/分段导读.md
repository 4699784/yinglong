# 《离骚》分段导读

> `[文学]` 为主。分段依常见教学结构，非古本原有标题。

## 一、开篇：世系、命名与修能

自「帝高阳之苗裔」至「来吾道夫先路」。  
自报高阳苗裔、寅年出生、名字「正则 / 灵均」，再写内美与修能、恐迟暮、愿为王前驱。  
→ 确立**贵族出身 + 自我修养 + 政治担当**三重身份。

## 二、政治실망与党人

自「昔三后之纯粹」至「伤灵修之数化」。  
以尧舜、桀纣对照，怨「灵修」（常释怀王）中道改路。  
→ 「美人—香草—君臣」象征系统于此定调。

## 三、培植众芳与好修

兰蕙杜衡的栽培失败，隐喻人才政策破产；饮露餐英写洁癖式修身。「虽九死其犹未悔」为全篇伦理高潮之一。

## 四、女嬃告诫与就重华陈词

女嬃责其过直；诗人南征向舜陈词，历数夏商暴君与汤武举贤。  
→ 神话历史化的自我辩护。

## 五、上征求女

驱龙乘凤、叩帝阍失败，求宓妃、有娀佚女、二姚皆不遇。  
→ 「求女」即求知己 / 求合君 / 求理想政治伴侣的多层隐喻 `[文学]`。

## 六、灵氛、巫咸与去留

占卜劝其远逝；巫咸举傅说、吕望等故事。诗人见芳草变秽，决计远行，却在临睨旧乡时「蜷局顾而不行」。  
→ **去国不能**的悲剧结构。

## 七、乱辞

「从彭咸之所居」：旧注多谓殷贤大夫谏君不听而投水；与沉江叙事互文。`[争议]` 彭咸事迹异说。

## 与《山鬼》的对照阅读

| 《离骚》 | 《山鬼》 |
|----------|----------|
| 求女不遇、陈辞不察 | 候神/恋人而不遇 |
| 香草自佩 | 薜荔女萝、折芳遗所思 |
| 政治时间焦虑（迟暮） | 「岁既晏兮孰华予」 |
| 上下求索的宇宙旅行 | 山中幽篁的封闭空间 |

二者共享「等待—赠物—失联」情感语法，而场景一在神话宇宙，一在巫祭山野。
