# 《河伯》翻译 · 解析 · 鉴赏

## 白话翻译

与你同游九河，暴风起，水波横。乘荷盖水车，两龙驾辕、螭为两旁。登昆仑四望，心飞扬浩荡。日将暮，怅然忘归，只把遥远水滨记在心怀。

鱼鳞为屋，龙为堂，紫贝阙，珠宫。神灵为何在水中？乘白鼋追逐文鱼，与你游于河渚。流冰纷纷冲下，你拱手东行。送美人到南浦，波涛滔滔来迎，鱼鳞般排列为我送行。

## 解析

人神同游—日暮怅—交手东行—南浦送别。河伯本北方大河之神而入楚祀，可见神谱的流动。结构上与《山鬼》同属「游从而后分离」。

## 鉴赏

「日将暮兮怅忘归」的「怅」，已不像《东君》观者的「憺」那样满足，而靠近离情。河上送别画面开阔，可作《山鬼》封闭山夜的对照。
