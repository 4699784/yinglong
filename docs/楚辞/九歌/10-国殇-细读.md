# 《国殇》翻译 · 解析 · 鉴赏

## 白话翻译

手持吴戈，身披犀甲，战车轮毂交错，短兵相接。旌旗遮日，敌人如云，箭雨交坠，士卒争先。敌人冲乱我的阵列，践踏行列；左边骏马倒毙，右边被刃所伤。两轮埋进土里，四马绊住，主帅仍举玉槌击鼓。天时怨怼，威灵震怒，严杀殆尽，弃骨原野。

出征就不打算回来，平原辽阔道路超远。带着长剑、挟着秦弓，头与身分离而心不悔。真是勇而又武，始终刚强不可侵凌。身虽死，神已成灵，你们的魂魄啊，是鬼中的英雄！

## 解析

对象是战死群魂，不是恋爱神。前半实录车战场面，后半完成祭祀升华：「神以灵」「鬼雄」。与《山鬼》之「鬼」同字异义。

## 鉴赏

读《九歌》若只沉浸于香草恋歌，会误解楚人。必须读《国殇》：鼓声、错毂、首身离而心不惩——这是同一文化的另一半心肺。刚柔对照，组诗才完整。
