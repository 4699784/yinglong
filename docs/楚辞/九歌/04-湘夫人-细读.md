# 《湘夫人》翻译 · 解析 · 鉴赏

## 白话翻译

帝子降临北渚，我望得目光酸楚。秋风袅袅，洞庭起波，木叶飘下。我登上白薠远望，与佳人约在黄昏张设帷帐。鸟为何聚集在水蘋中？鱼网为何挂在树上？（事与愿违的意象）沅有茝、醴有兰，思念公子却不敢说。恍惚远望，看流水潺湲。

麋为何在庭中觅食？蛟为何在水边？（再次错位）朝驰江皋，夕济西岸。听说佳人召我，将腾驾同往。在水中筑室，荷叶为盖；荪壁紫坛，花椒涂堂；桂栋兰橑，辛夷为楣、白芷为房……（极力铺写香草之屋）九嶷之神纷然来迎，灵来如云。

我把袂投入江中，单衣留在醴浦；取汀洲杜若，送给远方的人。时光不能骤得，且逍遥徘徊。

## 解析

与《湘君》为对歌式结构：一候男神，一候女神（传统说）。中段「筑室水中」是全《九歌》最铺张的「迎神工程」，越铺张，结尾「时不可骤得」越痛。

## 鉴赏

「嫋嫋兮秋风，洞庭波兮木叶下」以景开情，千古不厌。读时让秋风先经过身体，再进入香草建筑的幻觉，最后跌回「不可得」——三段落差即魅力。
