# 《大司命》翻译 · 解析 · 鉴赏

## 白话翻译

广开天门，我乘玄云。令旋风先驱，暴雨洒尘。你回翔 descending，越过空桑来就我。纷纷总总的九州，谁寿谁夭难道不在我！高飞安翔，乘清气驾驭阴阳。我与你一齐疾速，引导天帝到九冈。灵衣被被，玉佩陆离。一阴一阳，众人不知我做了什么。

折疏麻与瑶华，将送给离居的人。老境冉冉已到，不亲近就更疏远。乘龙车辚辚，高驰冲天。结桂枝久立，越想越愁。愁人怎么办？愿如今的情分不要亏缺。人命本有定数，离合又有谁能安排？

## 解析

神称掌握寿夭，权威极大；后半忽然落到「离居」「老」「疏」的人情。宇宙权力与个体衰老并置，是本篇张力。

## 鉴赏

结尾「固人命兮有当，孰离合兮可为」近乎命运论的叹息，与《山鬼》仍执着「思公子」不同：大司命选择认命，山鬼选择空等。
