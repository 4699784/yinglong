# 《东君》翻译 · 解析 · 鉴赏

## 白话翻译

旭日将出东方，照着我的栏杆与扶桑。我抚马安驱，夜色皎皎已明。驾龙车乘着雷，载云旗舒卷。长叹将上升，心中低回眷顾。声色多么娱人，观者安然忘归。

绷紧瑟弦，鼓声交作；钟磬悬在玉架。鸣篪吹竽，思念那美好的灵保。翠鸟翩飞，展诗会舞，应律合节，神灵到来遮蔽了日光。

青云为衣，白霓为裳，举长箭射天狼。我操弓矢又沦降，拿北斗酌桂浆。整顿缰绳高飞，在杳冥中向东行去。

## 解析

日神祭歌：出升—乐舞娱神—射天狼（祓除凶星）—酌酒—继续东行。公众性、庙堂性、刚健性都很强。「憺兮忘归」与《山鬼》「留灵修兮憺忘归」用语互参，场景一为群体观礼，一为山中私候。

## 鉴赏

读《东君》要听见钟鼓，看见长矢。它证明《九歌》不只婉转，也能金声玉振。与《国殇》同属「刚」的一极。
