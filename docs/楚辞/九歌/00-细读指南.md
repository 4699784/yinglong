# 《九歌》细读指南

## 怎么读这十一篇

1. 先读本目录之 `00-九歌总论.md` 与 `docs/荆楚文化/巫祭乐歌详论.md`。  
2. 每篇按：**正文（0X-篇名.md）→ 翻译解析鉴赏（0X-…-细读.md）**。  
3. 《山鬼》最深，专卷在 `docs/楚辞/山鬼/`；本目录 `09-山鬼.md` 仅作组诗通读用。  
4. 读完《湘君》《湘夫人》《山鬼》三篇「不遇」，再读《国殇》的刚烈，体会《九歌》内部对比。
