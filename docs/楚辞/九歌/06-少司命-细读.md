# 《少司命》翻译 · 解析 · 鉴赏

## 白话翻译

秋兰与麋芜，罗生堂下。绿叶素花，香气袭人。人们自有美好子女，你为何还愁苦？秋兰青青，绿叶紫茎。满堂美人，忽然独与我眉目传情。

来时不说话，去时不告辞，乘旋风载云旗。悲莫悲于生别离，乐莫乐于新相知。荷衣蕙带，倏忽来又忽而逝。傍晚宿在天帝之郊，你在云边等待谁？

想与你在咸池共沐，在阳坡晒干头发。望美人未来，临风恍然高歌。你以孔雀为盖、翠羽为旌，登九天抚彗星；持长剑护着幼艾——你最适合做人民的主宰。

## 解析

「目成」一瞬与「儵来忽逝」构成短促的亲密；名句「悲莫悲兮生别离，乐莫乐兮新相知」把聚散提升为人生公式。末写抚彗星、拥幼艾，神职（护幼／司命）重新压过恋歌。

## 鉴赏

把「新相知」的甜和「生别离」的苦压进两句，是《九歌》情感压缩技术的巅峰之一。可与《山鬼》长夜空等对照：一个瞬间极乐极悲，一个漫长疑信交作。
