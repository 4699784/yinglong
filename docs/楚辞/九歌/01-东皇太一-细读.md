# 《东皇太一》翻译 · 解析 · 鉴赏

## 白话翻译

吉日啊好时光，我们将恭敬地娱乐上皇。手抚长剑的玉柄，佩玉璆然作响。瑶席上安着玉瑱，一把把拿起琼芳。蕙草包着祭肉，下面垫着兰，奠上桂酒与椒浆。举起鼓槌击鼓，节奏疏缓地安歌，竽瑟齐鸣，舞蹈会合。神灵姿态偃蹇，服饰姣美，香气菲菲充满厅堂。五音纷然交会，神君欣欣然安乐康宁。

## 解析

- **功能**：组诗开篇的迎至上神，气氛和乐，几乎无「不遇」。  
- **结构**：择日→陈设→酒肴→乐舞→神喜。标准祭仪说明书的诗化。  
- **「太一」**：与秦汉「太一」信仰相关讨论多，楚「东皇太一」具体神格仍有争 `[争议]`。

## 鉴赏

先把「圆满」读出来，后面的《云中君》《湘君》《山鬼》之缺憾才有对照。香与乐写到「满堂」「繁会」，是《九歌》里少有的饱和幸福感。
