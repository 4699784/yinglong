# 《湘君》翻译 · 解析 · 鉴赏

> 整合并加厚原「翻译与简析」。正文见 `03-湘君.md`。

## 白话翻译

你犹豫不来，是谁把你留在沙洲？我妆扮得美好适宜，急驾桂舟而去。令沅湘无波，使江水安流。望着你却总不来——吹起参差，在思念谁？

驾飞龙北征，转道洞庭。薜荔为柏、蕙为绸，荪桡兰旌。望涔阳极浦，横大江扬起神灵。神灵未到极致，侍女为我叹息；我涕泪横流，暗暗伤怀。桂棹兰枻，像凿开冰雪。到水中采薜荔、到树梢取荷花——心不同则媒人徒劳，恩不深则易断绝。石濑浅浅，飞龙翩翩。交往不忠怨就长，约定不信，却告诉我「不得空闲」。

早晨我在江岸驰骋，傍晚停在北渚。鸟栖屋上，水绕堂下。我把玉玦投入江中，把佩饰留在醴浦；采芳洲杜若，将送给下女。时光不可再得，且逍遥徘徊。

## 解析

- **不遇类型**：期约落空 + 「不闲」说辞。  
- **礼物母题**：捐玦遗佩、采杜若——与《山鬼》折芳、采三秀同族。  
- **水上空间**：桂舟、洞庭、北渚，对《山鬼》山野空间。

## 鉴赏

「心不同兮媒劳，恩不甚兮轻绝」冷而准；「告余以不闲」则温而毒。把这两句与《山鬼》「然疑作」连读，能看见楚歌写「自我安慰如何破产」的谱系。
