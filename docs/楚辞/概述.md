# 楚辞概述

## 什么是「楚辞」

`[史实]` 「楚辞」指战国楚地兴起、以屈原作品为代表的韵文传统，汉代结集为书。句式多用「兮」字，意象重香草、神游、男女（人神）之情与楚地方言名物。

## 版本说明

古典正文据《楚辞》通行本（王逸《章句》—洪兴祖《补注》系统）转写为**简体**；异文不一一罗列，重要处在《山鬼》注中提示。现代导读为本库撰写的整理性解说。

## 阅读《九歌》的两个入口

1. **祭祀组诗**：神谱、迎送、巫表演。  
2. **抒情文学**：等待、赠别、不遇、家国（尤其《国殇》）。

《山鬼》同时是二者的典范交汇点。
