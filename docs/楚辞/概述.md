# 楚辞概述

## 什么是「楚辞」

`[史实]` 「楚辞」指战国楚地兴起、以屈原作品为代表的韵文传统，汉代结集为书。句式多用「兮」字，意象重香草、神游、男女（人神）之情与楚地方言名物。

## 本库收录与细读深度

| 文本 | 深度 |

未收全文：《天问》《九章》等——见参考书目，可作为下一阶段扩展。

古典正文据《楚辞》通行本（王逸《章句》—洪兴祖《补注》系统）转写为**简体**。现代导读与今译为本库整理。

## 两条阅读主线

1. **祭祀组诗线**：《九歌》细读指南 → 各篇细读 → 山鬼专卷。  
2. **政治抒情线**：屈原经历 → 《离骚》细读指南 → 与山鬼对读。

两者在「不遇」主题上会合。
