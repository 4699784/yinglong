# 应龙 · 山鬼研究语料库（yinglong）

面向 Project「shan gui」的先秦楚文化与楚辞研究起步包。收录**先秦时代（楚）历史语境**、**荆楚文化**、**屈原生平与学术争议**，以及《离骚》《九歌》（含《山鬼》深注）的古典文本与现代整理。

## 文字与体例

- **古典正文**：统一使用**简体字**（据通行《楚辞》文本转写；个别异文在注文中说明）。
- **现代解说**：简体中文。
- **层次标记**：
  - `[史实]` 有传世文献或考古可资互证者
  - `[传说]` 神话、民间叙事、后起附会
  - `[文学]` 文本解读、艺术分析（非史学断定）
  - `[争议]` 学界尚无共识者
- **引文**：尽量注明书名、篇章与通行版本；本库注释为整理性综述，**非**替代原注疏。

## 范围说明

本库为**可用的研究起步切片**，侧重与《山鬼》相关的楚地巫祭、自然神祇与《九歌》祭祀组诗语境；不追求楚史或楚辞学全书式完备。

## 许可与文本来源

先秦两汉经典原文属公有领域。整理说明、现代汉语导读与注释编排为仓库整理者撰写，引用时请注明本库路径。详细版本依据见 `docs/参考书目/`。
